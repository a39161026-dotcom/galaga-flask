# Galaga - Flask 웹 버전

원본 Java Swing 갤러그(`GalagaGame.java`)의 규칙과 수치를 옮긴 웹 버전입니다.
Flask가 페이지와 이미지를 서빙하고, 게임 로직은 브라우저의 JavaScript(Canvas)에서 돌아갑니다.
최고 점수는 Flask API(`/api/scores`)에 `scores.json`으로 저장됩니다.

## 실행 방법

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속

## 규칙

- 모든 적을 처치하면 다음 단계로 넘어갑니다.
- 단계 3, 6, 9는 보스전입니다. 보스를 처치하면 +2000점입니다.
- **난이도**: 단계가 시작될 때마다 쉬움 / 보통 / 어려움 중 하나가 무작위로 정해지고 화면에 표시됩니다.
  - 쉬움: 적이 덜 쏘고 느림, 보스 체력 80%
  - 보통: 기본값
  - 어려움: 적이 자주 쏘고 빠름, 보스 체력 130%
- **라운드**: 9단계(최종 보스)를 깨도 게임이 끝나지 않고 다음 라운드로 넘어갑니다. 라운드가 바뀔 때마다 적과 보스가 35%씩 더 강해집니다.
- 목숨 3개, 피격 시 1개 감소. 0개가 되면 게임 오버입니다. 적기와 직접 부딪히면 즉시 게임 오버입니다.
- 적 처치 시 20% 확률로 아이템이 드롭됩니다. 아이템 종류별 확률은 아래와 같습니다.

## 아이템

| 아이템 | 효과 | 지속 |
|---|---|---|
| ❤ 목숨 | 목숨 +1 (최대 5개) | 즉시 |
| ⚡ 속사 | 연사 속도 증가 | 3초 |
| 🔰 보호막 | 피격 무적 | 1.8초 |
| 🔫 쌍발사 | 한 번에 두 발 발사 | 3초 |
| 🎯 관통 | 총알이 적을 뚫고 지나감 | 3초 |
| 💣 폭탄 충전 | 폭탄 쿨다운 즉시 해제 | 즉시 |
| 💰 점수 2배 | 얻는 점수 2배 | 10초 |
| 🧊 감속 | 적과 보스 움직임과 발사 느려짐 | 5초 |
